# 🛍 Veloura - Android E-Commerce App

Veloura is a modern Android E-commerce application built using Clean Architecture and MVVM pattern.

---

## ✨ Features

- Splash Screen
- OnBoarding Flow
- Authentication (Login / Register)
- Products Home Screen
- Product Details Screen
- API Integration using Retrofit (DummyJSON)
- Navigation Component
- Clean Architecture
- MVVM Pattern

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Retrofit
- Coroutines
- Clean Architecture
- MVVM
- DummyJSON API

---

## 🏗 Architecture

The app follows Clean Architecture structure:

```
data/
domain/
presentation/
```

- Data Layer (API, Repository Implementation)
- Domain Layer (UseCases, Models)
- Presentation Layer (ViewModel, UI Screens)
